# Contributing

Thanks for your interest in the AI Agent Full-Stack Development Roadmap!

## How to Contribute

### Open an Issue

If you find:

- 📝 **Missing content** — an important topic not covered
- 🐛 **Factual errors** — inaccurate definitions or statements
- 🔗 **Broken links or formatting** — dead links, layout issues
- 💡 **Suggestions** — better organization, clearer wording

Please open an [Issue](https://github.com/qufei1993/ai-agent-fullstack-roadmap/issues) with the appropriate template.

### Submit a Pull Request

1. **Fork** this repo
2. Create a branch: `git checkout -b feature/xxx`
3. Make your changes with these conventions:
   - Use full-width CJK punctuation for Chinese content（，。、：；（）【】）
   - Add spaces between CJK and Latin characters
   - Keep style consistent with surrounding content
4. Commit: `git commit -m "describe your change"`
5. Push and create a PR

## Editorial Principles

When adding or modifying content, follow these principles:

- **A capability map, not a tool leaderboard** — tools are included to illustrate concept boundaries, not to rank popularity
- **When in doubt, leave it out** — unsure additions are better raised as Issues first
- **For Node.js / frontend developers** — terminology should be grounded in engineering, not confused with pure ML research
- **Prefer precision over hype** — avoid absolute claims ("best," "completely secure," etc.)
